# seg.py — 主动脉 CTA 分割工具

从一例主动脉 CTA 到一棵融合的血管树（网格 + STEP + 可拖动查看器 + 可核查的验收表），一条命令。

```
python seg.py run <病例目录>
```

**版本 1.1.0**（2026-11-15）。相对 1.0.0 的改动全部来自实测失败的修正，逐条记在 §7。

---

## 1 先跑一次 `check`

```
python seg.py check
```

打印五件事：本机 Slicer 的 Python、TotalSegmentator 的许可编号、三个分割模型的落点目录、几何模块与流水线的绝对路径、以及当前版本的**硬约束清单**（§7 的判据）。

许可是学术免费的那一个，编号存在 TotalSegmentator 自己的配置里：

```
PythonSlicer -c "from totalsegmentator.config import set_license_number; set_license_number('aca_xxx')"
```

三个模型与所需的许可：

| 任务 | 输出 | 许可 |
|---|---|---|
| `total` | 主动脉、弓上三支、双髂 | 不需要 |
| `renal_arteries` | **腹腔干 / SMA / 双肾动脉**（三类） | 需要（学术免费） |
| `coronary_arteries` | 完整左右冠脉 | 需要（同上） |

`renal_arteries` 这个任务名看起来只做肾动脉，实际输出 **celiac_trunk / superior_mesenteric_artery / renal_arteries** 三类——这是本工具内脏三支的来源。

## 3 命令

| 命令 | 作用 |
|---|---|
| `check` | 环境、许可、模型、路径、硬约束清单 |
| `run <case>` | 处理一例 → `<case>/out_pipeline/` |
| `batch <root>` | 处理 `root` 下所有病例 |
| `info <case>` | 验收表：网格体积/面数/水密/连通域，逐段节点数/半径/掩膜体积，缺段 |
| `render <case>` | 出 PNG |
| `--coronary` | 同时重建左右冠脉（多一个模型，约 4 分钟/例） |
| `--extra name=file.nii.gz` | 接入任何额外血管掩膜 |
| `--no-ts` | 复用缓存的分割结果 |

**不要用 `--skip-done` 来保证一致性。** 它只检查 `acceptance.json` 里的 `ok`，而那个文件可能是旧版本代码写的；跳过之后一批结果里会混着两代代码，且看不出来。要一致就全量重跑（模型走缓存，几何约 2–3 分钟/例）。

## 4 产物

| 文件 | 内容 |
|---|---|
| `model.stl` / `model.step` | 融合后的血管树 |
| `viewer.html` | 自包含可拖动查看器 |
| `seg.npy` | 各段 label 体数据 |
| `acceptance.json` | 逐段节点数/半径/掩膜体积、**每段半径剖面 `profiles`**、总体积/面数/水密/连通域、缺段、`ok` |
| `manifest.json` | 可复现凭据：版本、时间、耗时、输入 size+sha256、模型清单、许可、参数 |

`profiles` 是给 QC 用的：**不要再从 label 反推半径**（§7 第 6 条）。

## 5 流水线八步

**1 分割** —— 三个模型按 §1 的表取；内脏三支用专用模型，不用自研追踪器。

**2 中心线** —— 中轴点集，图直径（两遍 BFS）排序。不用最近邻排序：它来回折返，把扫掠壳撑大 50% 以上。

**3 半径** —— **主干**用法向平面 24 条射线的中位数；**分支**保留切向片计数法。两者混用会毁接口（§7 第 2 条）。

**4 口径** —— 不做体积反算缩放，体积只作报告项。

**5 接合** —— 支管等半径沿指向主干的方向穿入；主干沿**更顺直那条髂动脉自己的路径**延续 60 mm，另一条髂支**从分叉点出发**；主干末端渐缩受**斜率上限 0.22 mm/mm** 约束，不允许出现凸起。

**6 并集** —— 0.6 mm 共享体素网格 OR。

**7 表面** —— SDF 1.8 mm 模糊取零等值面；**网格若抽出多块，回体素阶段按 1/2/3 体素逐档闭运算重抽**，三档仍不通则显式告警。

**8 交付** —— 见 §4。

## 6 加一条新血管

1. **有掩膜**：`--extra 椎动脉=path\mask.nii.gz`，自动编号、建中心线、量半径、并入树。
2. **有 TS 类**：在 `aorta_pipeline.py` 的 `SEGMENTS` 表加一行
   ```python
   dict(key="vertebral_l", label=22, role="branch", ts=("vertebral_artery_left",), min_mL=0.05),
   ```
   `role` 取 `trunk` / `branch` / `bifurcation`，决定第 5 步怎么接；`min_mL` 必须给（§7 第 1 条）。

## 7 硬约束清单（每条都由一次实测失败换来）

**1 验收门槛必须按每段自身量级设。**
同一例的典型量级：主动脉 171 mL、腹腔干 1.6 mL、冠脉单支 **0.14 mL**——跨三个数量级。一个门槛管不了三段。
- 用「中轴 <8 mm 判短桩」→ 腹腔干（中轴天然 10–15 mm，更短）被误杀；
- 用「<0.30 mL 判无效」→ 冠脉（单支 0.14 mL）被误杀，29 例冠脉“缺失”其实全是被这条规则删掉的。
现在：`SEGMENTS` 每条带 `min_mL`，冠脉 0.06、其余 0.30，按**掩膜体积**判，不按中轴长度。

**2 主干与分支的半径量法不能混用。**
主干用射线中位数（弯曲段不失真）；分支若也用射线，**开口处的射线会读到主动脉半宽**，把支管做得比它自己的开口还粗——肾动脉曾因此量到 4.98 mm 并长成一个球。
判据：分支在开口处的半径不应超过它自己远端中位半径的 1.3 倍。

**3 不要为了“体积对上”做全局缩放。**
曾用 `sqrt(掩膜体积/管体积)` 反算，掩膜含所有分支的开口脚、管不含，比值恒 >1，把主干整体放大 **15%**（11.00 mm，图像 9.60 mm）。这是拿几何精度换一个好看的体积数字。

**4 分叉不是“两根管接到一根管末端”，也不是“三根管交于一点”。**
三管交于一点必留一圈领口（凸台+凹折）。做法：主干延续进更顺直那条髂支，另一条髂支**从分叉点**出发。
判据：`profiles` 里主干末端半径必须单调下降到与支管相当，不允许出现台阶或回升。

**5 侧支的路径必须真的从分叉点开始——改半径不算改路径。**
曾写过 `pp2[:n] = pp2[:n] + (P_join - pp2[0]) * 0.0`，乘 0 等于空操作，代码看着在做、实际什么都没做。**七次改动形态不变**就是这么来的。
判据：日志必须出现 `iliac_l leaves the fork (gap X mm)`，且 X 与 `profiles` 里支管首点坐标对得上。

**6 不要从 label 反推几何量，读 `profiles`。**
用「第一节髂支上方 10 mm 的主干宽度」扫全量叉口，报出“主干比两条髂支还细”（比值中位 0.53，最小 0.24）——解剖上不可能。错在指标：主动脉标签一直延伸到叉口以下，量到的是单侧支管。**指标错了，全量扫描只会把错误放大 30 倍。**

**7 诊断要看最终几何，不要看中间变量。**
两次踩坑：40 点采样的剖面把 12 mm 的过渡显示成相邻两点，据此以为有台阶；自造指标算错，据此以为全量超标。剖面采样点要足以分辨过渡长度。

**8 网格连通性故障先看 `union` 那行是不是已经 1 块。**
- 是 1 块 → 断在**表面抽取**（细颈被 1.8 mm 场模糊掐断），加粗体素补不了，要加闭运算重抽；
- 不是 1 块 → 才是并集阶段的问题，用细桥焊回。
p06 的第二块是 0.059 mL、40×11×12 mm、约 1.4 mm 粗的细丝，属于前者。

**9 布尔并集不能用。** 带端盖的管子做布尔，端盖与另一面相交处必留一圈台阶（“空窗”）。必须走共享体素网格 OR。

**10 形态学闭运算只能填凹，不能削凸。**
叉口外侧的圆头是凸的，闭运算动不了它；2 mm、3.5 mm 两档都试过，体积只变 0.3–2 mL。凸的东西要从**构造**上消掉（第 4、5 条），不是靠滤波。

## 8 已知限制（如实列出）

- **内脏支只到近段**：`renal_arteries` 模型标的是开口附近的一段（典型：腹腔干 22 mm、SMA 24 mm、肾动脉合计 28 mm），不追到肝、脾、肠系膜远端。下游 CFD 若要更远出口须再延长。
- **分支半径偏高**：腹腔干仍用切向片法，在粗短块上高估（典型 4.65 mm，真实约 3 mm）。主干已改射线法，分支尚未。
- **冠脉半径下限**：左冠 r 0.70 mm 已贴近射线步长，远端不可信。
- **重建的是管腔**，不含管壁。
- **分叉正下方仍有轻微不对称肩部**：仍在“锥 + 两柱”的并集框架内。
- **依赖本机**：Slicer 5.12.4 的 Python、TS 模型缓存、一个可写的临时目录（用户名含非 ASCII 字符时 joblib 可能失败，可在启动脚本里改 TMP）。
