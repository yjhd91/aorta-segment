# 主动脉 CTA → 融合血管树 流水线

一条命令，从一例 CTA 得到一个融合的血管树（网格 + STEP + 可拖动查看器 + 验收表）。

```bash
python aorta_pipeline.py <病例目录>
```

## 病例目录需要什么

```
<case>/
  ct.nii.gz         CTA 体数据
  crop_meta.json    {"sp_zyx":[z,y,x 间距], "org_c":[x,y,z 原点], "crop":[[k0,k1],[i0,i1],[j0,j1]]}
```

`crop_meta.json` 描述体数据被裁到哪个子体积、该子体积的原点与间距。如果手上只有原始 DICOM/NIfTI，先做一次 crop 并写出这个文件即可；`case_io.load_case` 按它读数据。

## 参数

| 参数 | 作用 |
|---|---|
| `--no-ts` | 跳过 TotalSegmentator，直接用它上次的输出（`<case>/ts_full/`）。调参时用。 |
| `--extra name=file.nii.gz` | **接入任意额外血管掩膜**（冠脉、椎动脉、腹腔干变异支……）。掩膜须与 `ct.nii.gz` 同网格；流水线会自动给它编一个 label，做中心线、量半径、并入树。 |
| `--enable <key>` | 启用 `SEGMENTS` 里预留但默认关闭的段（例如 `coronary_l`），前提是它的 TS 类或 `--extra` 数据已经存在。 |

## 产物（都在 `<case>/out_pipeline/`）

| 文件 | 内容 |
|---|---|
| `seg.npy` | 各段的 label 体数据（1 主动脉、2 头臂干、3 左颈总、4 左锁骨下、5/6 双髂、7 腹腔干、8 SMA、9/10 双肾；接入的额外血管从 30 起） |
| `model.stl` / `model.step` | 融合后的血管树网格与 CAD 交换格式 |
| `viewer.html` | 自包含的可拖动环绕查看器（几何内嵌；three.js 走 CDN，需联网） |
| `acceptance.json` | 每段的节点数、中位半径、掩膜体积、标定系数；总网格体积、面数、水密、连通域数；缺失段与预留段清单 |

## 流水线做了什么，以及为什么这么做

**1 分割.** 主干、弓上三支、双髂取 TotalSegmentator 的对应类；腹腔干与双肾用"主动脉壁→器官掩膜"的最小代价路径（造影血便宜、骨与空气昂贵），只保留路径上 HU>140 的连续段；SMA 从主动脉前壁下方取种子后沿 −k 逐层跟踪。这一段的质量取决于造影；腹腔干/SMA 在造影不足的病例上可能找不到，会在 `acceptance.json` 的 `missing` 里列出来，不会静默塞一个假桩。

**2 中心线.** 每段取中轴点集，用**图直径**（两遍 BFS）排出顺序。**不要用最近邻排序**——它会来回折返，把扫掠壳撑大 50 %以上。

**3 半径.** 在垂直于中心线的平面上量掩膜截面积。主干另取"内切球 × 椭偏系数"与它的较小值：切向片在弯曲段等于沿血管纵切、高估；内切球不随弯曲失真但受截面椭圆影响偏低，系数在平直站点标定。

**4 口径校准.** 每段半径剖面按 `sqrt(掩膜体积 / 管体积)` 缩放，使该段管的体积与掩膜体积一致。形状仍是平滑扫掠，只是口径被钉住。

**5 接合.**
- 支管以**等半径**沿指向主干中心线的方向延伸穿过去（不要锥形收头——锥形会在开口处留下可见收缩）；
- 两条髂支**从同一点分出**；主干最后 25 mm 按 `r = sqrt(rL² + rR²)` 连续渐缩到位。这是"分叉"和"两根管贴在端头"的区别。

**6 并集.** 所有管在**同一张 0.6 mm 网格**上栅格化后做 OR。**不要用布尔并集**：布尔并集在端盖与另一面相交处必然留一圈台阶（collars / 空窗）。

**7 表面.** 对并集的**有符号距离场**做 1.8 mm 高斯模糊后再取零等值面。SDF 模糊对零等值面位置的移动远小于 1 mm，但会把凹边与凸边同时圆掉——这是"焊在一起"和"拼在一起"的差别。之后清碎壳、Taubin 轻平滑（若平滑把网格弄成多块则回退）。

**8 交付.** 见上表。

## 增加一条血管 / 保留下一步的接口

两种方式，都不用改流水线的其余部分：

1. **有掩膜**：`--extra 冠脉左=path\to\mask.nii.gz`。流水线自动编号、建中心线、量半径、并入树。
2. **有 TotalSegmentator 类**：在 `SEGMENTS` 里加一行
   ```python
   dict(key="vertebral_l", label=22, role="branch", ts=("vertebral_artery_left",)),
   ```
   `role` 取 `trunk` / `branch` / `bifurcation`，决定它在第 5 步怎么接。

**冠脉**已经预留了两行（`coronary_l`、`coronary_r`，label 20/21，默认 `enabled=False`）：TotalSegmentator 的 `coronary_arteries` 任务需要商业/学术许可，没有许可时用 `--extra` 传入自己的冠脉掩膜即可，`--enable coronary_l` 让它参与。

## 对一例新病例的预期

- 主动脉 + 双髂 + 弓上三支：只要 CTA 覆盖到、造影够，通常能出。
- 腹腔干 / SMA / 双肾：依赖造影与器官掩膜，可能缺失；缺失会列在 `missing`。
- 冠脉：默认不出，需要许可或自己的掩膜。

## 已知限制

- 分叉正下方仍有轻微不对称肩部（"锥 + 两柱"的并集特性）；彻底消除需要在分叉处生成显式过渡曲面。
- 内脏支根部有轻微喇叭口（T 形交接几何）。
- 网格是**管腔**，不含管壁。
